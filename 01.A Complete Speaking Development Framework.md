## 🎯 A Complete Speaking Development Framework
##### INPUT → NOTICE → CONTROL → RECONSTRUCT → IDEATE → SPEAK → FEEDBACK → REPEAT → TRANSFER

| Stage                         | هدف                              | فعالیت اصلی                                      |
| ----------------------------- | -------------------------------- | ------------------------------------------------ |
| **01 · Input**                | دریافت زبان واقعی                | Listen / Read / Watch                            |
| **02 · Notice**               | دیدن اینکه زبان چطور استفاده شده | Vocabulary · Grammar · Pronunciation · Chunks    |
| **03 · Control**              | کنترل زبان جدید                  | Pronunciation drill · Chunk practice · Shadowing |
| **04 · Reconstruct**          | تبدیل Input به Output اولیه      | Retell the content without the script            |
| **05 · Ideate**               | ساختن ایده برای صحبت             | Questions · Prompts · Examples · Reasons         |
| **06 · Organise**             | مرتب‌کردن فکر                    | Point → Reason → Example → Result                |
| **07 · Supported Speaking**   | صحبت با کمک                      | Keywords / prompts / sentence starters           |
| **08 · Independent Speaking** | صحبت بدون کمک                    | 60–120 sec spontaneous response                  |
| **09 · Feedback**             | تشخیص نقاط ضعف                   | Content · Language · Pronunciation · Fluency     |
| **10 · Repeat & Improve**     | اصلاح و اجرای مجدد               | Record → Review → Re-record                      |
| **11 · Transfer**             | انتقال یادگیری به موضوع جدید     | New question / new context                       |

## 🧠 بخش مهم: Idea Generation
به‌جای اینکه بگوییم:

> **“Talk about social media.”**

از یک Idea Ladder استفاده می‌کنیم:

> **TOPIC → POSITION → REASON → EXAMPLE → CONSEQUENCE → PERSONAL VIEW**

مثلاً:
```
Topic: Social media
↓
Position: Is it mostly useful or harmful?
↓
Reason: Why?
↓
Example: Can you give a real example?
↓
Consequence: What happens because of this?
↓
Personal view: What do you think?
```
## 🎓 Teacher-Guided Speaking Framework
```
                         ┌──────────────────────────┐
                         │   EXPERT TEACHER / COACH │
                         │ Diagnose · Guide · Model │
                         │ Prompt · Correct · Adapt │
                         └────────────┬─────────────┘
                                      │
INPUT → NOTICE → CONTROL → RECONSTRUCT → IDEATE
                                      ↓
                           SUPPORTED SPEAKING
                                      ↓
                           INDEPENDENT SPEAKING
                                      ↓
                            FEEDBACK & COACHING
                                      ↓
                            REPEAT & IMPROVE
                                      ↓
                                TRANSFER
```
اما نقش استاد در هر قسمت متفاوت است:

| مرحله                    | نقش استاد                                                              |
| ------------------------ | ---------------------------------------------------------------------- |
| **Input**                | انتخاب محتوای مناسب سطح و هدف                                          |
| **Notice**               | هدایت توجه به زبان مهم و پنهان                                         |
| **Control**              | مدل‌سازی pronunciation، chunks و spoken patterns                       |
| **Reconstruct**          | کمک به بازسازی بدون تبدیل تمرین به حفظ‌کردن                            |
| **Ideate**               | آموزش **چگونه ایده بسازیم**، نه دادن جواب آماده                        |
| **Supported Speaking**   | سؤال‌دادن، prompting و scaffolding                                     |
| **Independent Speaking** | عقب‌نشینی تدریجی و مشاهده عملکرد واقعی                                 |
| **Feedback**             | تشخیص اینکه مشکل واقعاً چیست: Language؟ Fluency؟ Ideas؟ Pronunciation؟ |
| **Repeat & Improve**     | تعیین ۲–۳ هدف مشخص برای اجرای بعدی                                     |
| **Transfer**             | قرار دادن زبان‌آموز در یک موضوع/موقعیت جدید                            |


نکته کلیدی

استاد نباید همیشه بیشتر کمک کند؛ باید کمک را به‌تدریج کمتر کند:

Teacher Support
██████████ → ██████ → ███ → █ → Independent

این همان چیزی است که می‌توانیم اسمش را بگذاریم:

Guided → Supported → Independent → Transferable Speaking

و یک اصل خیلی مهم:

> **A good speaking teacher does not simply correct what the learner says; they diagnose why the learner cannot say it, provide the right support, and gradually remove that support.**
